I'm Rajesh (RJ).

I build infrastructure: the control planes and platforms that other people's software runs on.

Right now that's AstroPulse, which I've built end to end myself. It started as a control plane for running applications in your own cloud: clusters, deployment, networking, upgrades and rollback, with the same approvals and audit whether a person or an AI agent makes the change.

Now I'm extending it to AI infrastructure. GPUs, model serving and training are a different kind of workload from the ones I've worked on, but the problem is one I know well: every infrastructure product rebuilds the same production machinery around the part that actually makes it different. I want AstroPulse to be that machinery, so AI infrastructure companies can keep their own runtime, scheduler or router and run it on AstroPulse instead of building the platform underneath themselves.

Before AstroPulse I was at Confluent, working on how to run and scale their streaming platform for both cloud and on-prem customers.
